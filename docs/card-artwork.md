# Manga card artwork

Generated with the built-in image-generation tool for this project. All subjects
are fictional adult women, age 30 or older. Six portraits are distributed across the default deck;
card identities and effects remain in the existing title and description UI.
User-uploaded artwork overrides the defaults. The existing card back is retained.
Each vertical PNG was converted into a lightweight WebP asset for fast loading.

- `assets/fate-cards/manga/bald-latex.webp`: Premium portrait manga playing-card
  illustration; beautiful adult woman with a completely shaved bald head, confident
  expression, opaque black latex fashion catsuit with gold trim, holding a gold card.
  Plum/charcoal background, warm gold light, sophisticated detailed linework, no text
  or border, non-explicit fashion illustration.
- `assets/fate-cards/manga/undercut-swimsuit.webp`: Portrait manga game-card artwork;
  beautiful adult woman with closely shaved sides and a swept long violet top,
  opaque burgundy one-piece swimsuit, holding gold dice. Plum/charcoal background,
  fine gold light, detailed linework, no text or frame, non-explicit.
- `assets/fate-cards/manga/emerald-bald-swimsuit.webp`: Elegant adult Black woman,
  fully shaved head, emerald glossy asymmetric one-piece swimsuit, seated on a
  burgundy chaise and holding a gilded hand of cards. Warm gold and dark plum.
- `assets/fate-cards/manga/copper-undercut-swimsuit.webp`: Adult woman with a
  copper-red undercut and sweeping curls in a sapphire-and-magenta shiny one-piece,
  leaning on an art-deco railing, gold dice raised, cheerful expression.
- `assets/fate-cards/manga/platinum-undercut-teal-latex.webp`: Adult woman with a
  platinum-blonde undercut, glossy teal high-neck full-length latex-style outfit,
  gold-trimmed gloves and an ornate playing card.
- `assets/fate-cards/manga/violet-undercut-red-latex.webp`: Adult woman with a
  black/violet asymmetrical undercut, ruby-red full-length glossy latex-style
  outfit, holding an antique gilded key beside a casino table.

Cards use the following fixed, meaningful defaults (repeats are intentional):

| Portrait | Fate cards |
| --- | --- |
| Bald / black latex | Lucky Skip, Devil's Five |
| Violet undercut / burgundy swimsuit | Double or Nothing, Fate Roulette |
| Bald / emerald swimsuit | Nothing, Pick Your Poison |
| Copper undercut / blue-magenta swimsuit | Swap Fate, Chaos Weights |
| Platinum undercut / teal latex | Rarest Fate, Sealed Envelopes |
| Violet undercut / red latex | Double Forfeit, Triple Trouble |
